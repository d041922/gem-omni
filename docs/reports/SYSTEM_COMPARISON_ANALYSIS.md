## 1. 멀티 에이전트 시스템

### 문서 제안

**5개 전문 에이전트 구성:**

| 에이전트 | 전문 분야 | 도구 |
|:---|:---|:---|
| Fundamental Agent | 재무제표, 공시자료 | RAG 분석기, 재무 계산기 |
| Sentiment Agent | 뉴스, 소셜미디어 | NLP 감성 분석, 뉴스 요약 |
| Valuation Agent | 주가, 기술적 지표 | Yahoo Finance API, 변동성 모델 |
| Risk Control Agent | 리스크 한도, 규제 | 리스크 체크 엔진, 시나리오 시뮬레이터 |
| Manager Agent | 최종 의사결정 | 토론 관리, 보고서 생성 |

**협업 프로토콜:**
- 구조화된 토론 (Round Robin)
- 반추(Reflection) 과정
- 다수결 또는 신뢰도 가중치 합의
- 합의 불가 시 보수적 "보유(HOLD)" 권장

### GEM OMNI 현황 (Phase 2)

**4개 전문 에이전트 구성:**

| 에이전트 | 전문 분야 | 상태 |
|:---|:---|:---:|
| Fundamental Analyst | ROE, 부채비율, 재무 건전성 | ✅ 구현 |
| Sentiment Analyst | 뉴스 감성, 시장 심리 | ✅ 구현 |
| Valuation Analyst | 기술적 분석, ADX, MFI | ✅ 구현 |
| Moderator | 3명 의견 종합, 합의 | ✅ 구현 |

**협업 메커니즘:**
- CrewAI Task context 전달
- 각 에이전트 독립 분석 → Moderator 종합
- 합의 알고리즘 (3:0, 2:1, 분열 시 보류)

### 비교 분석

| 항목 | 문서 제안 | GEM OMNI | 격차 |
|:---|:---:|:---:|:---:|
| 에이전트 수 | 5개 | 4개 | -1 |
| Risk Control Agent | ✅ | ❌ | 미구현 |
| 토론 라운드 | 명시 없음 | 4 Task | 유사 |
| 반추(Reflection) | ✅ | 🟡 부분 | 개선 필요 |
| 합의 알고리즘 | ✅ | ✅ | 구현됨 |

**평가: ⭐⭐⭐⭐ (4/5)**
- Risk Control Agent 추가 필요
- 반추 과정 명시적 구현 고려

## 3. 데이터 분석 및 RAG

### 문서 제안

**정성적 분석:**
- FinBERT 활용 감성 분석 (금융 도메인 특화)
- 전체 시장 과열/공포 수준 감지

**RAG 파이프라인:**
1. 검색 및 인덱싱 (벡터 데이터베이스)
2. 하위 작업 분해
3. 도구 호출 (API, 코드 인터프리터)
4. 종합 및 리포팅

### GEM OMNI 현황

**감성 분석:**
- ✅ yfinance 뉴스 + Gemini 분석
- ❌ FinBERT 미사용 (Gemini로 대체)
- ✅ 긍정/중립/부정 점수 산출

**RAG:**
- 🟡 부분 구현 (프롬프트 파일 캐싱)
- ❌ 벡터 데이터베이스 없음
- ❌ 하위 작업 분해 명시적 구현 없음

### 비교 분석

| 항목 | 문서 제안 | GEM OMNI | 격차 |
|:---|:---:|:---:|:---:|
| 감성 분석 | FinBERT | Gemini | 대체 구현 |
| 벡터 DB | ✅ | ❌ | 미구현 |
| RAG 파이프라인 | ✅ 완전 | 🟡 부분 | 개선 필요 |
| 도구 호출 | ✅ | 🟡 부분 | 개선 필요 |

**평가: ⭐⭐⭐ (3/5)**
- FinBERT vs Gemini: Gemini로 충분 (실용적)
- 벡터 DB: 현재 규모에서는 불필요
- RAG 고도화: 장기 과제

## 4. 자율적 행동 유도 (넛지)

- 저축 유도: 월급 입금 감지 → "여유 자금 ETF 적립" 제안

**자율 실행:**
- Supervised Autonomy (사용자 승인 후 실행)
- 매달 정해진 날짜 자동 배분
- 모든 거래 투명 기록

**자율 실행:**
- ❌ 전혀 구현 안 됨
- ✅ 분석 결과 제공만

### 🔴 즉시 적용 가능 (High Priority)

#### 1. Risk Control Agent 추가
```python
# agents/crewai_agents/stock_agents.py
def create_risk_control_agent() -> Agent:
    """
    리스크 한도 체크, 포트폴리오 집중도 경고
    """
    return Agent(
        role="리스크 관리자",
        goal="포트폴리오 리스크 한도 체크 및 경고",
        backstory="리스크 관리 전문가...",
        ...
    )
```

**효과:**
- 포트폴리오 집중도 자동 체크

**예상 소요:** 2-3시간

## 전략적 선택

### GEM OMNI의 차별화 전략

**문서 제안 (엔터프라이즈급):**
- 대형 기관 투자자용
- 자동화, 넛지, 자율 실행
- 복잡한 인프라
- 높은 비용

**GEM OMNI (개인 투자자용):**
- ✅ 조회형 (Pull 방식)
- ✅ 사용자 주도 의사결정
- ✅ 단순하고 투명
- ✅ 저비용 ($5/월 미만)

**전략적 우위:**
1. **안전성**: 자동 실행 없음 → 법적 리스크 최소
