# Spec: Research Engine Logic Augmentation (v1.2)

## 1. 개요 (Overview)
`ResearchEngine`의 내부 로직을 보강하여 데이터의 가독성을 높이고, 퀀트 분석 결과와 리포트 템플릿 사이의 문맥적 연결을 강화한다.

## 2. 세부 보강 명세 (Logic Specs)

### 2.1 한국형 수치 포맷팅 (Data Formatting)
- **Market Cap**: 원시 수치(Raw int)를 한국식 단위(조, 억)로 변환하여 템플릿에 주입.
    - 예: `3,000,000,000,000` -> `3.0조`
- **Yield**: 소수점 2자리 제한 및 `%` 기호 부착.

### 2.2 지능형 요약 생성 (Automated Insights)
마스터가 AI 리포트를 바로 이해할 수 있도록 점수 기반 요약을 생성한다.
- **Score >= 80**: "강력한 모멘텀이 확인되는 최우선 순위 종목입니다."
- **Score >= 60**: "안정적인 상승 흐름을 보이고 있으며 진입 시점을 조율 중입니다."
- **Score < 40**: "보수적인 접근이 필요하며 리스크 관리가 우선되는 구간입니다."

### 2.3 필드 매핑 및 방어 (Safe Mapping)
- `MarketScreener`의 `details` 객체와 `AnalysisManager`의 `verdict` 데이터를 리포트 템플릿 필드에 1:1 대응시킨다.
- 데이터 누락 시 `None`이 아닌 "분석 데이터 확인 불가" 메시지를 명시적으로 주입한다.

## 3. 검증 계획
- **UT-REP-LOGIC**: 포맷팅 함수가 거액의 시가총액을 "X조" 형식으로 정확히 변환하는지 확인.
- **UT-REP-VERDICT**: 점수에 따른 요약 문장이 정상적으로 생성되는지 확인.
