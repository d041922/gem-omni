# Specification: Wealth Intelligence Control Center (WICC) 4.0

## 1. Vision
마스터의 'USER_PROFILE'과 '글로벌 Macro'를 동기화하여 최적의 부의 경로를 안내하는 지능형 통제실.

## 2. Strategic Modules
### A. Intelligence Foundation (Data)
- **Macro Matrix**: 환율, 미국채 10년물, VIX, BTC, 주요 지수 실시간 연동.
- **Human Mapping**: 티커 대신 직관적인 종목명 표시.
- **Profile Alignment**: [Core / Scaling / Optional] 분류 체계 복구 및 계좌별 그룹화.

### B. Cognitive Engine (AI)
- **Macro Expert Crew**: 경제/정치 상황을 반영한 포트폴리오 영향도 분석.
- **Opportunity Hunter**: 마스터의 성향에 맞는 유망 섹터(전력, 로봇, 바이오 등) 스크리닝.
- **Priority Action**: 데이터에 기반한 '오늘의 매수/매도' 우선순위 리스트.

### C. Master Interface (UI/UX)
- **Hierarchy Design**: 거시 상황 -> 포트폴리오 요약 -> AI 액션 -> 상세 자산 목록.
- **Visual Clarity**: 수익률 색상 지표, 금액 단위 최적화(억/만), 소수점 정리.

## 3. Implementation Protocol
- 모든 작업 후 `Dev-Pilot Audit` (Integrity Check) 통과 필수.
- `USER_PROFILE.md`를 모든 AI 판단의 최우선 순위로 설정.
